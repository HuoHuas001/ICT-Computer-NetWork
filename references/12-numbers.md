## A.8 公式与算法

| 公式 | 说明 |
|---|---|
| 可用主机数 = **2ⁿ − 2** | n = 主机位数 |
| 子网数 = **2ᵏ** | k = 向主机位借位数 |
| 块大小 = **256 − 掩码最后一段** | 快速定位子网 |
| 网络地址 = IP **AND** 掩码 | 广播 = 网络地址 + 主机位全 1 |
| 汇总 = 取所有明细的**公共前缀** | 掩码 = 最长公共位数 |
| **STP RPC** = 沿途入方向 Cost 之和 | 802.1t：GE = 20000 |
| **OSPF Cost = 参考带宽 / 接口带宽** | 缺省 100 Mbps → GE = 1 |
| **TCP 发送窗口 = min(拥塞窗口, 接收窗口)** | 流量控制 + 拥塞控制 |
| **NTP Offset = [(T2−T1)+(T3−T4)]/2** | Delay = (T4−T1)−(T3−T2) |
| **Base64**：3 字节 → 4 字符 | 用于邮件/MIME 编码 |
| **EUI-64**：MAC 中间插 `FFFE`，第一字节 U/L 位取反 | 生成 IPv6 接口标识 |
| **ACL 通配符**：0 = 严格匹配，1 = 任意 | 反掩码 |
| 最大活动链路数（LACP） | 与对端保持一致 |

## A.9 协议/技术归属速查

| 技术 | 层次 | 说明 |
|---|---|---|
| ARP / ICMP / IGMP | 网络层（辅助） | ARP 靠广播解析 MAC |
| OSPF / RIP / BGP | 网络层（路由协议） | OSPF 直接封装在 IP（89）；RIP 用 UDP 520；BGP 用 TCP 179 |
| PPP / PPPoE / HDLC / 以太网 | 数据链路层 | PPPoE 以太类型 0x8863/0x8864 |
| TCP / UDP | 传输层 | 端口寻址 |
| DNS / DHCP / HTTP / FTP / SMTP / NTP / SNMP / CAPWAP | 应用层 | 见 A.1 端口表 |
| TLS/SSL | 传输层与应用层之间 | 保护 HTTP/FTP/邮件 |
| 802.1Q / STP / LACP | 数据链路层 | 交换技术 |
