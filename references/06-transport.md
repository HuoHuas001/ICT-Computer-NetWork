# 第6章 传输层


### 6.1 TCP

**首部（固定 20 B，含选项最长 60 B）**

| 字段 | 长度 | 说明 |
|---|---|---|
| 源端口 / 目的端口 | 16+16 bit | 标识进程 |
| **Sequence Number** | 32 bit | 本报文段数据第一个字节的序号 |
| **Acknowledgment Number** | 32 bit | 期望收到对方**下一个**字节的序号（= 已收到最后字节 +1） |
| Header Length | 4 bit | 以 **4 字节**为单位（5 = 20 B） |
| Reserved | 4 bit | 置 0 |
| **Control bits** | 6 bit | **URG / ACK / PSH / RST / SYN / FIN** |
| Window | 16 bit | 接收窗口（可接收字节数），用于流量控制 |
| Checksum | 16 bit | 校验首部 + 数据（**强制**） |
| Urgent Pointer / Options | 16 bit / 可变 | 选项如 MSS、窗口扩大、SACK |

**三次握手（建立连接）**

```text
Client                       Server
  |--- SYN, seq=x ----------->|      (SYN_SENT → SYN_RCVD)
  |<-- SYN+ACK, seq=y, ack=x+1|      (ESTABLISHED)
  |--- ACK, seq=x+1, ack=y+1 ->|      (ESTABLISHED)
```
- 第三次握手可以携带数据；前两次不能携带数据。
- 为什么三次：防止**已失效的连接请求**突然到达导致服务器资源浪费，并同步双方序号。

**四次挥手（关闭连接）**

```text
Client                    Server
  |--- FIN, seq=u -------->|   FIN_WAIT_1 → CLOSE_WAIT
  |<-- ACK, ack=u+1 -------|   FIN_WAIT_2
  |<-- FIN, seq=w ---------|   LAST_ACK
  |--- ACK, ack=w+1 ------>|   TIME_WAIT（等 2MSL 后 CLOSED）
```
- 为什么四次：TCP 全双工，两个方向需各自关闭（**半关闭**）。
- **TIME_WAIT 等 2MSL**：保证最后 ACK 能到达、让旧连接的残留报文在网络中消失。
- 常见状态：CLOSED、LISTEN、SYN_SENT、SYN_RCVD、ESTABLISHED、FIN_WAIT_1/2、CLOSE_WAIT、CLOSING、LAST_ACK、TIME_WAIT。

**可靠传输机制**

| 机制 | 说明 |
|---|---|
| 序号 + 确认 | 字节流编号，**累计确认**（对按序到达的最后一个报文确认） |
| **滑动窗口** | 发送窗口 = min(拥塞窗口, 接收方通告窗口)；窗口通告指出剩余缓冲 |
| 超时重传 | 每发一段启动定时器，超时未确认则重传；**RTO** 动态计算 |
| 快重传 / 选择确认 | 收到 3 个重复 ACK 立即重传（SACK 可只重传丢失段） |
| 流量控制 | 由接收方窗口控制发送速率 |
| 拥塞控制 | 慢启动、拥塞避免、快重传、快恢复 |

- **MSS = MTU − IP 头 − TCP 头 = 1500 − 20 − 20 = 1460 B**。
- **Socket（套接字）= IP 地址 + 端口号**；一条 TCP 连接由**两个 Socket** 唯一标识（四元组）。
- TCP 面向**字节流**、全双工、面向连接；UDP 面向**报文**。

**端口分类**

| 范围 | 类别 | 例子 |
|---|---|---|
| 0–1023 | 知名端口 | HTTP 80、Telnet 23、FTP 21 |
| 1024–49151 | 注册端口 | 用户安装的软件 |
| 49152–65535 | 动态/私有端口 | 客户端源端口（一般 >1023 随机） |

### 6.2 UDP

- **首部仅 8 B**：源端口(16) + 目的端口(16) + 长度(16) + 校验和(16)。
- 特点：**无连接、不可靠、无拥塞控制、开销小、时延低、面向报文**（应用给多长就发多长，不拆分不合并）。
- 需要可靠性的应用要在**应用层自己实现**（如 TFTP 的确认重传）。
- 典型：DNS(53)、DHCP(67/68)、TFTP(69)、NTP(123)、SNMP(161/162)、RIP(520)、CAPWAP(5246/5247)、语音视频。

**TCP vs UDP**

| 维度 | TCP | UDP |
|---|---|---|
| 连接 | 面向连接（三次握手） | 无连接 |
| 可靠性 | 可靠（确认/重传/排序） | 不可靠 |
| 传输单位 | 字节流 | 数据报 |
| 首部 | 20 B | 8 B |
| 流量/拥塞控制 | 有 | 无 |
| 适用 | 文件、网页、邮件 | 实时音视频、DNS、广播/组播 |
