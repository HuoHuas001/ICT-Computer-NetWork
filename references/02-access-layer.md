# 第2章 网络访问层


### 2.1 物理层

**传输介质**

| 介质 | 要点 |
|---|---|
| 双绞线 UTP/STP | 以太网最常用；STP 有铝箔/铜网屏蔽，抗干扰强、更贵 |
| 同轴电缆 | 早期总线型以太网、有线电视 |
| 光纤 | 单模（芯径 **9 µm**，远距离、低衰减、贵）；多模（**50/62.5 µm**，短距离、便宜） |
| 串口电缆 | WAN 常用（V.24 / V.35），实验室用串口直连模拟 |
| 无线 | 电磁波，2.4G/5G |

- 光纤连接器：**SC、LC**（数通最常用）、FC、ST、MPO/MTP、MU。

**线序（必考）**

| 标准 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T568A | 白绿 | 绿 | 白橙 | 蓝 | 白蓝 | 橙 | 白棕 | 棕 |
| T568B | 白橙 | 橙 | 白绿 | 蓝 | 白蓝 | 绿 | 白棕 | 棕 |

- 直通线：两端**同序**（PC↔交换机）；交叉线：一端 A 一端 B（同类设备互连）。
- 4 对线绞距周期约 **38.1 mm**，逆时针扭绞；RJ45 由 IEC 60603-7 标准化。

**信号与编码**

- 基带信号/基带传输：未调制原始信号直接在信道传输；通带（频带）传输：先调制再传。
- 编码（数字→数字）：不归零 NRZ、曼彻斯特（**频率更高、自带时钟同步**）、差分曼彻斯特、4B/5B。
- 调制（数字→模拟）：**调幅 AM / 调频 FM / 调相 PM**。

**复用技术**

| 复用 | 关键点 |
|---|---|
| FDM 频分 | 各用户占不同频带 |
| TDM 时分 | 各用户占固定时隙（空闲也浪费） |
| STDM 统计时分 | 按需动态分配时隙 |
| WDM 波分 | 光纤中多波长 |
| CDM 码分 | 不同码型，互不干扰（抗干扰强、保密好） |

### 2.2 数据链路层与以太网

**链路层功能**：成帧、差错校验（奇偶校验 / 校验和 / CRC）、物理寻址、可靠传输、流量控制。
- 子层：**LLC**（逻辑链路控制，与上层对接）+ **MAC**（介质访问控制，与物理层对接）。以太网 = IEEE **802.3**，WLAN = **802.11**。

**MAC 地址**
- 长度 **48 bit（6 Byte）**，写法 `XX-XX-XX-XX-XX-XX`；前 **24 bit = OUI**（厂商，IEEE 分配），后 24 bit 厂商自定。
- 单播（可作为源/目的）、广播 `FF-FF-FF-FF-FF-FF`（只能作目的）、组播（**只能作目的**，如 STP 的 `01-80-C2-00-00-01`）。
- MAC 表项**老化时间默认 300 s**。

**CSMA/CD（有线共享）**：先听后发、边发边听、冲突停发、随机延迟重发（二进制指数退避）。
**CSMA/CA（无线）**：无线无法边发边听检测冲突，改为**避免**：载波侦听 + 随机退避 + **确认 ACK** + 可选 RTS/CTS；并使用停止等待协议。

**以太网帧格式**

| 字段 | Ethernet II | 长度 |
|---|---|---|
| 前导码 + SFD | 7 B + 1 B（`10101010…` + `10101011`） | 8 B |
| 目的 MAC | — | 6 B |
| 源 MAC | — | 6 B |
| 类型 Type / 长度 Length | Type ≥ 0x0600(1536) 为 Ethernet II；≤1500 为 802.3 | 2 B |
| 数据 Data | 最小 **46 B** | 46–1500 B |
| 填充 Pad | 保证帧长 ≥64 B | 可变 |
| FCS | CRC 校验 | 4 B |

- 帧长 **64–1518 Byte**（不含前导码），MTU = 1500。
- Type 常见值：**0x0800 = IPv4**，**0x0806 = ARP**，**0x8100 = 802.1Q VLAN**。
- IEEE 802.3 帧把 Type 换成 Length，靠 **LLC（DSAP/SSAP/Ctrl）+ SNAP** 标识上层（DSAP/SSAP=0xAA 时是 SNAP 帧）。

### 2.3 交换机工作原理

| 行为 | 触发条件 |
|---|---|
| **泛洪 Flooding** | 广播帧、组播帧、**未知单播帧**（表里查不到目的 MAC） |
| **转发 Forwarding** | 表中命中目的 MAC，且出接口 ≠ 入接口 |
| **丢弃 Discarding** | 命中表项但出接口 = 入接口；或端口安全违规 |

- 学习：收到帧后**记录「源 MAC ↔ 入端口」**；同一 MAC 从别的端口出现则**更新（漂移）**。
- **冲突域**：共享介质上所有节点集合；交换机每个接口是**一个冲突域**（隔离冲突域）。
- **广播域**：广播帧能到达的范围；交换机**不隔离**广播域（需 VLAN 隔离），路由器隔离广播域。
- 同网段通信全过程：ARP 请求（广播）→ 交换机泛洪 + 学习 → 目的主机单播 ARP 应答 → 之后正常转发。
- 三层交换机 = 二层交换 + 路由转发（一次路由、多次交换）。
