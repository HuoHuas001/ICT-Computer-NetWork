# 第17章 答题层：官方口径对照与判断题陷阱库

> 本章不教网络原理，只解决**"原理没错但答案错"**的问题。
> 适用：HCIA-Datacom / HCIP 判断题、单选"以下说法正确的是"、多选题。

## 17.1 第一判断原则：先看主语，再看原理

```text
读到题目 → 圈出主语
   ├─ 主语是具体方案/产品（CloudFabric、CloudCampus、NCE-Fabric、NCE-Campus、
   │  NCE-WAN、USG6000、CE 系列、AirEngine、iMaster…）
   │     → 以【该方案文档】为准，禁用 RFC / 通用原理反驳
   └─ 主语是通用技术（VXLAN、OSPF、802.11、IPSec、TCP…）
         → 以【标准 + 华为教材通用描述】为准
```

**铁律**：方案文档里"必须/只能/仅支持"这类表述，是**方案限定**，不是**技术真理**。
用通用原理去否定方案表述 = 用错尺子。

| 表述 | 通用技术层面 | 方案层面 | 考试该按哪个 |
|---|---|---|---|
| "VXLAN 必须用 BGP EVPN 作控制面" | 不一定（可泛洪学习/OpenFlow） | **CloudFabric 就是 EVPN** | 主语带 CloudFabric → **按方案** |
| "跨 DC 互联使用 VXLAN 隧道，不含 MPLS 承载" | 运营商 DCI 常用 VPLS/MPLS L3VPN | **CloudFabric Multi-Site 就是 VXLAN** | 主语带 Multi-Site → **按方案** |
| "AP 必须通过 AC 管理" | 云 AP 无 AC | CloudCampus 云 AP 由 NCE-Campus 管 | 看题目是否提云管理 |
| "NAT 必须在路由器上做" | 防火墙/云网关也能做 | USG 有独立 nat-policy | 主语带 USG → 按防火墙 |

## 17.2 主语识别清单（看到就切换口径）

| 主语关键词 | 归属方案 | 口径来源 | 常见"方案限定"结论 |
|---|---|---|---|
| **CloudFabric / Multi-POD / Multi-Site / Border Leaf / NCE-Fabric** | 数据中心 | CloudFabric 方案文档 | VXLAN + BGP EVPN；Spine 不接服务器；去堆叠用 M-LAG；跨 DC 用 VXLAN 隧道 |
| **CloudCampus / 云 AP / NCE-Campus / 云管理** | 园区 | CloudCampus 方案文档 | 云 AP 免 AC；AP 注册靠 Option 43/148、DNS、RQC；业务本地转发 |
| **NCE-WAN / SD-WAN** | 广域 | SD-WAN 方案文档 | 选路基于应用/链路质量，叠加 IPSec |
| **USG6000 / 防火墙 / 安全区域 / HRP** | 安全 | USG 产品文档 | 默认拒绝；状态检测；NAT 与策略分离 |
| **CE 系列 / CloudEngine** | DC 交换机 | 产品文档 | 支持 M-LAG、VXLAN、EVPN |
| **AirEngine / Wi-Fi 6** | 无线 | 产品文档 | OFDMA/BSS Coloring 是效率技术 |
| **S 系列 / 园区交换机** | 园区 | 产品文档 | iStack/CSS 堆叠 |

## 17.3 判断题六种陷阱类型

| 类型 | 手法 | 识别信号 | 对策 |
|---|---|---|---|
| **① 方案限定当通用** | 把某方案的做法说成"必须/所有场景" | "必须""只能""一定""仅支持" | 圈主语，回到 §17.1 |
| **② 通用当方案** | 用 RFC 结论否定方案表述（反向） | 题目主语是方案名，选项讲通用原理 | 以方案文档为准 |
| **③ 张冠李戴** | 把 A 产品的功能安到 B 产品 | NCE-Fabric/Campus/WAN 互换；iStack/M-LAG 互换 | 背"控制器/双活"对应表 |
| **④ 数字错位** | 端口/位数/时间/优先级写错一位 | 4789↔4789、VNI 24↔12、5246↔5247、161↔162 | 回 `12-numbers.md` 核 |
| **⑤ 方向/顺序颠倒** | NAT 与策略顺序、源/目的 NAT、上下行 | "先源 NAT 再策略""策略写公网地址" | 背 §16.5 流水线 |
| **⑥ 绝对化/过头** | "完全防止""100% 检测""彻底消除" | 任何"完全/彻底/永远" | 安全类几乎全为**错** |

**绝对化词清单（见到先怀疑）**：必须、只能、唯一、一定、所有、任何、完全、彻底、100%、永远、绝不、无需、不需要。

## 17.6 答题流程 checklist（判断题 20 秒版）

```text
1. 圈主语 → 方案名？→ 切方案口径（§17.1）
2. 找绝对化词 → 有？先按"错"假设，再验证
3. 找数字 → 端口/位宽/时间/优先级，回 12-numbers.md 核
4. 找顺序 → NAT/策略、源/目的、上下行、请求/响应
5. 找方向 → 谁发起、谁转发、谁决定
6. 兜底：安全类"完全/彻底/100%"几乎全错；"默认动作"类必查
7. 仍不确定 → 选与"教材/方案文档原话"最接近的表述，不要用原理"推理"出新结论
```

## 17.7 表述对照速查（官方原话 → 考试口径）

| 官方原话风格 | 考试要理解为 |
|---|---|
| "支持 / 推荐" | 方案内**常规做法**（不是唯一可行） |
| "必须 / 需要" | 方案内**强制前提**（出了方案不一定成立） |
| "缺省 / 默认" | 未配置时的行为，**判断题高频** |
| "可选 / 可以" | 存在但非必需，别答成"必须" |
| "建议" | 最佳实践，答"正确"通常安全 |

## 17.8 本章使用方式

- 做题前扫 §17.3（陷阱类型）与 §17.6（checklist）；
- 做题后凡错一题，按 §17.4 模板登记一行，并**追加到 §17.5 表**；
- 同一陷阱类型累计 ≥3 次，说明该方向的知识缺口在方案文档，去补对应章节分片（14/15/16）。
